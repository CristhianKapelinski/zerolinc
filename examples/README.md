# Sample tickets

`tickets_sample.csv` contains the five anonymized incident reports that the reference study publishes as its open sample (SecLINC artifact, [AI-Horizon-Labs/SecLINC](https://github.com/AI-Horizon-Labs/SecLINC), `sample/teste/amostra.xlsx`), converted to the ZeroLINC input schema (`incidente_id`, `conteudo`, `categoria`). No other ticket from the evaluation corpus is redistributed here.
